# Hi, I'm Mouad Zizi 👋

### Senior Flutter Developer | Mobile App Development | Full-Stack Engineer

I'm a Senior Flutter Developer and Full-Stack Engineer based in Morocco, with **10+ years of software development experience**.

I specialize in building production-ready cross-platform mobile applications for Android and iOS using Flutter and Dart. I also develop modern web applications, backend services, APIs, and complete software platforms.

I have experience working on large-scale mobile applications, ride-hailing platforms, sports applications, marketplaces, SaaS products, business management systems, and custom software solutions.

I enjoy taking projects from concept to production, focusing on clean architecture, maintainable code, performance, and reliable user experiences.

- **Mobile Development:** Flutter, Dart, Android, iOS, Java, Kotlin.
- **State Management:** BLoC, Cubit, Provider, GetX.
- **Navigation & Architecture:** GoRouter, Clean Architecture, MVVM, Dependency Injection.
- **Frontend Development:** React.js, Next.js, Astro, TypeScript, JavaScript, Tailwind CSS.
- **Backend Development:** Node.js, NestJS, Express.js, PHP, Laravel.
- **Databases:** PostgreSQL, MongoDB, MySQL, SQLite, Redis.
- **Backend Services:** Firebase, Supabase, REST APIs, WebSockets.
- **Integrations:** Stripe, Payment Gateways, Digital Wallets, Google Maps, GPS Tracking, OTP Authentication, Push Notifications.
- **DevOps:** Docker, Linux, Nginx, Git, CI/CD.
